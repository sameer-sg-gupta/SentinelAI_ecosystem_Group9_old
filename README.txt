SENTINELAI LANDING PAGE — REVISION 2

Open index.html in a modern browser. No installation, build tool, account,
server or internet connection is required. All assets are local.

CONTENTS
index.html       Semantic landing page and copy
styles.css       Responsive desktop/mobile styling
app.js           Audience views, workflow, navigation and enquiry dialog
factory.js       3D geometry renderer with orbit, hotspots and plan view
assets/          Logo and illustrative generated photography

FUNCTIONALITY
- Responsive single-page landing page with existing #workflow anchor.
- Three audience perspectives, each with a conceptual product preview.
- Lightweight interactive 3D factory rendered using Canvas 2D projection
  of 3D geometry. Drag to orbit; numbered markers select findings.
- Equivalent keyboard-operated finding buttons and top-down plan view.
- Five-step workflow with a sample evidence action.
- Pilot enquiry dialog downloads a local text file. No data is sent.
- No cookies, analytics, remote scripts or external image dependencies.

CONTENT BOUNDARIES
The supplied SentinelAI presentation contains differing development stages.
This page uses the conservative proposed pilot: one insurer, 3-5 sites,
one independent verification partner, one machine category. No premium
credits and no pricing, coverage or claims decisions from pilot outputs.
Dashboard records and factory findings are illustrative. Verification of
implementation does not establish effectiveness or reduced losses.
No insurer or verifier partnership is implied. Photographs are AI-generated.
The graphical mark is the original shield-eye from presentation slide 1.
Its source pixels are unchanged. The page displays a viewport of the exact
embedded deck image. Arial and deck blue/cyan colours replace the former
invented green identity. Original deck asset: ppt/media/image8.png.
The CSS .original-logo displays a viewport of that original PNG.
It is not a vector recreation or a newly generated logo.

ACCESSIBILITY / PERFORMANCE
Keyboard-native buttons, semantic landmarks, visible focus styles, modal
keyboard handling, reduced-motion support and no continuous animation.
Factory rendering occurs on input or resize rather than in an idle loop.
The 3D model is illustrative, not an industrial digital twin.
